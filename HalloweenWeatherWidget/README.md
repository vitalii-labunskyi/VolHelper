# Halloween Weather Widget

Android GPS weather widget, Ukrainian text, Halloween icons, dark/light large/compact variants.

## Source upload

Upload the contents of `HalloweenWeatherWidget-Halloween-Theme-v5.zip` into this folder (not the ZIP itself). The archive contains the Gradle project, Java sources, fonts and graphical assets.

## APK build

After the project sources are present, run the `Build Halloween Weather APK` action from the repository Actions tab, or push a change under `HalloweenWeatherWidget/`. Download the APK from the successful run's Artifacts section.

**Current status:** Folder and workflow created. Source archive and binary resources are not uploaded yet, therefore an APK cannot be built from this repository yet.

Note: A GitHub Actions workflow must live in the repository root under `.github/workflows`, not inside this directory.
